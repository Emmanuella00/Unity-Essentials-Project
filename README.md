# Unity Essentials Pathway — Practice Scenes

**Check out my scenes:** [Play on Unity Play](https://play.unity.com/en/games/5ba1493b-9d89-4e0f-9e57-7d3d4be77c8c/webbuilds)

A set of small Unity scenes built while completing the Unity Essentials Pathway — covering editor basics, 3D physics, audio, and 2D gameplay scripting in C#.

## Scenes
- Playground / Navigation — Editor basics
- Kid's Room (3D) — Rigidbody physics, bouncing ball
- Kitchen — Spatial audio
- Living Room — C# scripting basics
- Top-Down 2D — Movement, walls, collectibles

## Run It
Clone the repo, open in Unity Hub (6.5+), pick a scene from `Assets/_Unity Essentials/Scenes/`, and hit Play.
